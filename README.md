## ⚙️ About Me

I'm an **Industrial Automation Engineer & Software Developer** working at the intersection of:

```text
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   MACHINE → CONTROLLER → MOTION → PLC → HMI → SOFTWARE    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

My work focuses on building, integrating and troubleshooting real-world
industrial systems — especially **CNC machines, motion control, HMI,
PLC and manufacturing software**.

I enjoy solving problems where **hardware and software meet**.

> **Don't just fix the symptom. Find the root cause.**
